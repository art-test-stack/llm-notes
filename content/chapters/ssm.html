Learning objectives

You should be able to connect classical state-space equations to sequence models, derive the recurrent and convolutional views, explain selective state-space models, compare their training and inference properties with attention, and avoid conflating a learned hidden state with a physically identified state.

Classical physical state-space systems

A continuous-time linear time-invariant (LTI) system is written:

dh(t)/dt = A h(t) + B u(t) y(t) = C h(t) + D u(t)

Here h(t) ∈ ℝⁿ is a model state, u(t) ∈ ℝᵖ an input, and y(t) ∈ ℝᵐ an output. In a physical model, coordinates may represent quantities such as current, velocity, or temperature and can be tested for identifiability. A neural SSM reuses this mathematical form as a learned sequence layer; its hidden coordinates are not automatically physical, observable, or uniquely identifiable.

Continuous-time and discrete-time SSM derivation

Variation of constants over a sampling interval \Delta gives:

h(t + Δ) = exp(ΔA) h(t) + ∫₀^Δ exp((Δ - τ)A) B u(t + τ) dτ

The matrix exponential is \operatorname{exp}(\Delta A) = \sum _{j=0}\infty (\Delta A)^j/j!; it is the fundamental solution of the homogeneous linear ODE, not an elementwise exponential. Under a zero-order hold (ZOH), u(t + τ) = u_t throughout the interval, so:

Ā = exp(ΔA) B̄ = ∫₀^Δ exp(sA) B ds = Δ φ₁(ΔA) B φ₁(Z) = (exp(Z) - I) Z⁻¹ (defined by its power series at singular Z) h_t = Ā h_{t-1} + B̄ u_t y_t = C h_t + D u_t

When A is nonsingular, A \bar{B} = (\bar{A}-I)B. Solve that linear system only when it is well conditioned; never form A⁻¹. Robust alternatives compute \phi _{1} with scaling-and-squaring or Krylov methods, or use one block exponential:

exp(Δ [ A B ]) = [ Ā B̄ ] [ 0 0 ] [ 0 I ]

This remains valid for singular A and avoids cancellation in \operatorname{exp}(\Delta A)-I. Diagonal neural SSMs can evaluate the scalar \text{expm}1(\Delta a)/a elementwise, with the analytic limit \Delta near a=0.

A continuous LTI system is asymptotically stable when every eigenvalue of A has negative real part. Exact ZOH maps each mode as \bar{\lambda} = \operatorname{exp}(\Delta \lambda ), hence \mid \bar{\lambda}\mid \lt 1. A discrete recurrence is asymptotically stable when the spectral radius \rho (\bar{A}) \lt 1. Forward Euler instead requires \mid 1+\Delta \lambda \mid \lt 1, so a stable continuous system can become unstable at a large step. Eigenvalues are not the whole numerical story: a non-normal A can have large transient amplification even with stable eigenvalues, and an ill-conditioned eigenbasis makes kernel generation and gradients fragile.

Boundary between domains: the derivation is shared mathematics. In the neural sections below, A, B, C, and h are learned sequence-layer parameters and activations unless stated otherwise. The later control-theory sections return explicitly to physical models.

Recurrent, convolutional, and scan views

For the discrete LTI recurrence and initial state h_{-1}, repeated substitution yields:

h_t = Ā^{t+1} h_{-1} + Σ_{j=0}^{t} Ā^{t-j} B̄ u_j = Ā^{t+1} h_{-1} + Σ_{k=0}^{t} Ā^k B̄ u_{t-k} y_t = CĀ^{t+1}h_{-1} + Σ_{k=0}^{t} K_k u_{t-k} + D u_t K_k = C Ā^k B̄

With zero initial state, this is a causal convolution. The fixed kernel exists because Ā, B̄, and C are invariant across time: the contribution of an input depends only on lag k, not on its absolute position or intervening token values. The direct term D is either added separately or folded into lag zero as K_{0} \leftarrow K_{0} + D.

There are three execution views of the same LTI layer:

  • Recurrence: one O(N) structured state update per token and fixed state memory; ideal for autoregressive decoding and streaming.
  • Convolution: generate K_{0}\ldots K_{L-1}, then use an FFT convolution in roughly O(L \operatorname{log} L); all training positions are handled in parallel.
  • Associative scan: represent token t by the affine map (Ā_t,b_t), where b_t=B̄_tu_t. Compose adjacent maps with (A_{2},b_{2}) \otimes (A_{1},b_{1})=(A_{2}A_{1},A_{2}b_{1}+b_{2}). Because composition is associative, a tree scan has logarithmic parallel depth even when the per-token parameters vary.
# streaming inference: carry h across calls
for u_t in tokens:
    h = A_bar @ h + B_bar @ u_t
    y_t = C @ h + D @ u_t
    emit(y_t)

Training usually pays for kernel construction plus FFTs, or for a parallel scan, to expose sequence-level parallelism. Decode uses the recurrence because only one new token is available and retaining h avoids recomputing the prefix. See LLM inference and KV-cache execution for the analogous prefill/decode split.

Structured state-space models

An unrestricted dense A ∈ ℝᴺˣᴺ has N² parameters, costs O(N^{2}) per recurrent step, and can require O(N^{3}) factorization or matrix-exponential work. A sequence layer has many feature channels, so repeating that cost per channel is impractical. It is also difficult to optimize long memory while keeping every mode stable and the eigenvectors well conditioned.

  • Diagonal: A=\operatorname{diag}(\lambda _{1},\ldots ,\lambda _N). Powers, exponentials, and recurrence cost O(N); complex-conjugate modes can represent oscillations while producing real outputs.
  • Diagonal plus low rank (DPLR): A=Λ-PQ\cdot. Diagonal resolvents are cheap and the low-rank correction is handled with Woodbury-style identities, retaining richer coupling.
  • Normal plus low rank (NPLR): a unitarily diagonalizable normal component plus a small-rank correction. The normal basis controls conditioning; the low-rank term recovers the structured dynamics of important initializations.
  • HiPPO-inspired: start from dynamics designed to maintain coefficients of a projection of the input history onto an orthogonal basis. The spectrum spans multiple timescales, providing long memory before learning rather than asking random initialization to discover it.

Long memory needs modes close to the discrete unit circle, but placing them too close causes slow decay, large resolvents, and sensitive gradients. Common safeguards parameterize continuous real parts as negative (for example \operatorname{Re}(\lambda )=-\text{softplus}(\theta )), constrain or regularize the discrete radius, initialize timescales across a logarithmic range, normalize input/output factors, and compute exponentials and scans in at least FP32. Stable eigenvalues do not prevent transient growth in a non-normal matrix; parameterization, eigenvector conditioning, and finite-precision tests matter together.

S4 and related architectures

S4 (Structured State Space for Sequences) was designed to make long-memory state-space layers trainable and computationally efficient on long sequences. Its key move is not merely “use a recurrence”: it combines a HiPPO-derived structured state matrix with an NPLR/DPLR representation that makes the entire convolution kernel tractable.

For an LTI layer of length L, S4 constructs K_{k}=C\bar{A}^k\bar{B}. Rather than multiplying a dense matrix L times, it evaluates a generating function/resolvent such as C(I-zĀ)⁻¹B̄ at FFT roots. Diagonal resolvents plus the low-rank correction reduce this to structured Cauchy-like operations. An inverse FFT produces the time-domain kernel; the input and kernel are then convolved using FFTs. Implementations cache or regenerate the kernel during full-sequence training and convert the same learned discrete system to the one-step recurrence for decoding.

S4D observes that after moving the HiPPO operator to a useful eigenbasis, a purely diagonal A can retain much of the long-range behavior. For a diagonal system, each scalar mode contributes C_{n} \bar{B}_n \bar{\lambda}_n^k, so kernel construction and recurrence are much simpler. DSS and related diagonal variants make different choices for initialization, normalization, and complex parameterization, trading some expressivity for simpler, faster, better-conditioned implementations. The practical distinction is: S4 preserves a low-rank correction to structured dynamics; S4D-style layers discard it and rely on well-initialized independent modes.

Selective SSMs and Mamba

A fixed LTI kernel applies the same compression rule at every position. A selective SSM lets the token determine the step size and input/output projections:

Δ_t = softplus(W_Δ x_t + b_Δ)       # positive step / retention control
B_t = W_B x_t                       # what is written
C_t = W_C x_t                       # what is read
Ā_t = exp(Δ_t A)
B̄_t = ∫₀^{Δ_t} exp(sA) B_t ds
h_t = Ā_t h_{t-1} + B̄_t x_t
y_t = C_t h_t + D x_t

Parameter sharing and exact tensor contractions differ by implementation, but the mechanism is the same: \Delta _t changes how quickly old state decays, B_{t} selects what enters, and C_{t} selects what becomes visible. Unrolling now gives:

y_t = C_t [Σ_{j=0}^{t} (Π_{r=j+1}^{t} Ā_r) B̄_j x_j] + D x_t

The coefficient connecting x_j to y_t depends on the endpoints and every intervening input-dependent transition. It is therefore not one fixed convolution by relative lag. It is still a linear recurrence conditional on the generated parameters, so the affine-map operator above enables a selective scan.

Mamba block

  1. An input projection expands the model width and creates a main stream plus a gate stream.
  2. A short causal depthwise convolution and SiLU activation mix local neighbors in the main stream.
  3. Linear projections produce selective \Delta _t, B_{t}, and C_{t}; learned stable A supplies the base dynamics.
  4. A selective scan updates the per-channel state and returns the readout.
  5. The readout is multiplied by an activated gate, then an output projection returns to model width; the block is used with normalization and a residual connection.

A performant implementation fuses projection-adjacent operations, discretization, scan, gating, and state writes so it does not materialize an intermediate tensor for every (batch, time, channel, state) element in high-bandwidth memory. It tiles sequence chunks, keeps partial state in registers/shared memory where possible, and chooses layouts with contiguous channel/state access and coalesced loads. This is why a custom selective-scan kernel can matter more than the recurrence’s asymptotic complexity; see compilation and custom kernels.

Mamba-2 develops state-space duality: with additional structure such as a scalar transition shared within a head, the causal input/output map is a structured semiseparable matrix. The same layer can then be evaluated recurrently, by scan, or by blocked matrix multiplications resembling attention kernels. This is a computational duality, not a claim that softmax attention and an SSM have identical content-addressing behavior.

Attention versus SSMs

Dense causal attention gives every query a content-dependent weighted lookup over stored keys and values. An SSM repeatedly compresses the prefix into a finite-dimensional state. That distinction, rather than complexity alone, explains the quality and serving trade-offs. For more context mechanisms, see long-context modelling and cross-attention.

Hybrid attention–SSM architectures use SSM layers for cheap streaming and broad history compression, then insert occasional global/local attention for precise content-addressable retrieval. The central design question is which information can be summarized and which must remain explicitly addressable.

Implementation

Tensor shapes and state

Let input x have shape [B,L,D]: batch, sequence, and model width. A block may project to inner width H. With per-channel state dimension N, a simple selective state is h:[B,H,N]; broadcast diagonal dynamics are A:[H,N]; per-token step sizes are commonly \Delta :[B,L,H]; and selective factors are broadcastable to the update, for example B_t,C_t:[B,L,N] or grouped/head-specific variants. The conceptual full trajectory [B,L,H,N] should normally not be stored outside a training kernel.

N is the state capacity per channel/head, not the Transformer model width and not the sequence length. Increasing it can improve memory capacity but raises parameters, scan work, recurrent-state bytes, and numerical exposure.

Scan-oriented pseudocode

# x: [B,L,H], A: [H,N], initial_state: [B,H,N]
delta, B_sel, C_sel = project_selective_parameters(x)
a = exp(delta[..., None] * A[None, None, ...])       # [B,L,H,N]
b = zoh_input_factor(delta, A, B_sel, x)             # [B,L,H,N]

# Affine prefix composition; combine(right, left) means right ∘ left.
def combine(right, left):
    a_r, b_r = right
    a_l, b_l = left
    return (a_r * a_l, a_r * b_l + b_r)

prefix_a, prefix_b = associative_scan(combine, (a, b), axis=1)
h = prefix_a * initial_state[:, None, ...] + prefix_b
y = reduce_state(C_sel * h) + D * x
final_state = h[:, -1]

The elementwise form assumes diagonal A; matrix-valued blocks replace products with matrix multiplication. Production kernels generate parameters and scan in chunks rather than materializing a, b, or h at these full logical shapes.

Stateful streaming API

state = model.init_state(batch_size)       # SSM state + causal-conv buffer
logits, state = model.step(token, state)   # exactly one position
logits, state = model.prefill(chunk, state)
state.reset(rows=finished_sequences)       # reset before a new document/request

Chunked prefill must return the same final state and valid-token outputs as one full scan, up to floating-point roundoff. Padding must be an identity transition—keep the old state and mask the output—not merely a zero input, because a zero input may still decay the state through Ā_t. Reset on document boundaries and when a batch slot is reused; do not let one request’s state leak into another. Packed sequences need an explicit segment-reset flag inside the scan.

Keep exponentials, accumulated state, normalization statistics, and scan reductions in FP32 when FP16/BF16 underflows or loses long-timescale increments; cast activations around the fused kernel as appropriate. Clamp or stably parameterize \Delta, use expm1/\phi _{1} near zero, preserve conjugate pairing for complex modes, and test long rollouts for NaN/Inf, drift, and chunk-equivalence.

Evaluation

A useful comparison reports a quality frontier rather than only asymptotic cost:

  • Language modelling: validation loss/perplexity and downstream accuracy at matched parameters, training tokens, optimizer/data, context length, and training compute.
  • Long-range recall: vary delay, number of key–value pairs, distractors, and required exactness on associative-recall, copy, induction, and needle-style tasks; separate extrapolation beyond training length.
  • Streaming latency: prefill time, time to first token, steady-state inter-token latency, and p50/p95 under realistic batch sizes and concurrency.
  • State memory: bytes per request for every layer’s SSM state and convolution buffer versus attention KV-cache bytes as context grows.
  • Throughput by length: training tokens/s, prefill tokens/s, and decode tokens/s over a sweep of sequence lengths; report hardware, precision, fusion/compiler settings, and peak memory.
  • Quality-matched serving: compare memory and latency only after matching achieved task quality, or plot a Pareto frontier. Match decoding settings and include any hybrid attention cache.
  • Ablations: state size N; fixed versus input-dependent \Delta, B, and C; local convolution; gate; initialization; scan precision; and the frequency of attention layers in hybrids.

Also test streaming correctness: full sequence versus arbitrary chunking, reset and padding behavior, very long recurrent rollouts, and train-convolution versus inference-recurrence agreement. These catch implementation failures that perplexity alone can hide.

Classical control-theory concepts

Controllability

The pair (A,B) is controllable when inputs can move the system across the state space. For an n-dimensional LTI system, the controllability matrix is:

𝒞 = [B, AB, A²B, …, A^{n-1}B]

Full rank implies controllability.

Observability

The pair (A,C) is observable when the internal state can be reconstructed from outputs. The observability matrix is:

𝒪 = [C; CA; CA²; …; CA^{n-1}]

Full rank implies observability.

These concepts are highly relevant to physical state estimation and observers. They should not be transferred mechanically to a learned language-model hidden state without specifying the learned dynamics and measurements.

Observers

A Luenberger-style observer is:

ĥ_{t+1} = A ĥ_t + B u_t + L(y_t - C ĥ_t)

The innovation y_t - Cĥ_t corrects the model prediction. Kalman filters extend this idea under stochastic process and measurement noise assumptions.

In hybrid physics–ML systems, a learned component can estimate residual dynamics, uncertain parameters, noise models, or observer corrections while preserving known physical equations.

PMSM project connection

The motor-control project uses a genuine physical state-space model: electrical currents, rotor speed/position, torque, coordinate transforms, feedback control, and state/torque estimation. Its value for applied engineering is the understanding of dynamics, hidden-state reconstruction, simulation assumptions, and stability—not a claim that a language-model SSM is the same object.

Physics–ML hybrid design

A robust hybrid can take forms such as:

known dynamics + learned residual
known state transition + learned observation model
known simulator + learned surrogate component
observer innovation + learned correction

Evaluation should include stability, conservation or constraint violations, parameter identifiability, extrapolation beyond the training envelope, and uncertainty under sensor noise or model mismatch.

Failure modes

  • treating linear-time complexity as automatic wall-clock speed;
  • assuming fixed state preserves every historical detail;
  • unstable discretization or poorly conditioned dynamics;
  • hidden-state explosion or vanishing memory;
  • selective gates saturating;
  • comparing attention with an SSM at unmatched parameters or quality;
  • calling a learned latent variable a physical state without identification;
  • using simulator accuracy as proof of real-world validity;
  • omitting observability or excitation limits in state estimation.
