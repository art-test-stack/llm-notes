1. Deterministic transport

Start with a tractable base random variable x₀ ∼ p₀, usually Gaussian noise, and evolve it through the ordinary differential equation

dxₜ/dt = vₜ(xₜ), t ∈ [0, 1].

The time-dependent vector field vₜ assigns a velocity to every point. If Φₛ→ₜ(x) denotes the solution at time t initialized at x at time s, then Φ is the flow map and

xₜ = Φ₀→ₜ(x₀), pₜ = (Φ₀→ₜ)♯ p₀.

The pushforward notation says that the probability of any set under pₜ equals the probability of its preimage under the flow. A trained generative flow aims for p₁ ≈ p_data.

If vₜ(x) is continuous in time and Lipschitz in x (with suitable growth bounds), the ODE has a unique solution. Uniqueness prevents two trajectories from meeting and then separating: the inverse map is obtained by integrating the same ODE backward. If the field is sufficiently smooth, the flow is a differentiable bijection, or diffeomorphism. Singular fields, blow-up, or loss of uniqueness can destroy global invertibility.

A one-dimensional transport example

Let x₀ ∼ N(0, 1) and target N(μ, σ²), with σ > 0. Couple the endpoints by x₁ = μ + σx₀ and use

xₜ = (1 - t)x₀ + t x₁ = aₜx₀ + tμ, aₜ = 1 + t(σ - 1).

Then pₜ = N(tμ, aₜ²), and the Eulerian velocity—written using the current position rather than the hidden starting point—is

vₜ(x) = μ + (σ - 1)(x - tμ)/aₜ.

At t = 1, the map is exactly x₀ ↦ μ + σx₀. Because aₜ > 0, it stays invertible. Its one-dimensional divergence is ∂ₓvₜ = (σ - 1)/aₜ, so integrating the instantaneous log-density change gives -∫₀¹ ∂ₓvₜ dt = -log σ, precisely the log-Jacobian correction for scaling by σ.

2. Continuity equation

Let Ωₜ = Φ₀→ₜ(Ω₀) be any region moving with the flow. Deterministic transport neither creates nor destroys probability, hence

d/dt ∫_{Ωₜ} pₜ(x) dx = 0.

Applying the transport theorem converts the change over the moving region into a local balance law:

0 = ∫_{Ωₜ} [∂ₜpₜ(x) + ∇·(pₜ(x)vₜ(x))] dx.

Because this holds for every material region, the integrand must vanish:

∂ₜ pₜ + ∇·(pₜ vₜ) = 0.

This is probability conservation. The flux pₜvₜ carries probability across boundaries: density rises where more flux enters than leaves. Expanding the divergence gives

∂ₜpₜ + vₜ·∇pₜ + pₜ ∇·vₜ = 0.

Along a trajectory, the first two terms form the material derivative, so

dpₜ(xₜ)/dt = -pₜ(xₜ) ∇·vₜ(xₜ).

Negative divergence compresses volume and raises density; positive divergence expands volume and lowers density. A probability path and a velocity field are compatible exactly when they satisfy this continuity equation (up to regularity and boundary conditions).

3. Continuous normalizing flows

A continuous normalizing flow (CNF) parameterizes vₜ, commonly with a neural network, and uses the ODE flow as an invertible density model. Dividing the material-density equation by pₜ(xₜ) yields the instantaneous change-of-variables formula:

d log pₜ(xₜ)/dt = -∇·vₜ(xₜ) = -tr(∂vₜ/∂x).

Therefore, for a data point x₁, integrate the state backward to x₀ while accumulating

log p₁(x₁) = log p₀(x₀) - ∫₀¹ ∇·vₜ(xₜ) dt.

This supports likelihood computation without forming the determinant of a full discrete Jacobian. It does not make likelihood free: an ODE solver evaluates the network repeatedly, and the divergence requires derivatives of every output with respect to its corresponding input.

Exact traces can be expensive in high dimension. Hutchinson estimation uses a random vector ε with E[εεᵀ] = I:

tr(J) = Eε[εᵀJε], J = ∂vₜ/∂x.

A vector–Jacobian product estimates the trace without materializing J. One or a few probes reduce compute but introduce variance. Solver tolerances, number of function evaluations, divergence estimation, and differentiation through the solve dominate CNF training and likelihood cost.

4. Flow matching objective

Flow matching begins by choosing a target probability path pₜ from p₀ to p_data and a velocity uₜ that generates it. It then fits a model vθ(t, x) by regression:

L_FM(θ) = E_{t ∼ U[0,1], x ∼ pₜ} [ ||vθ(t, x) - uₜ(x)||² ].

The marginal target uₜ(x) is usually unavailable. Conditional flow matching (CFM) makes the problem tractable by introducing conditioning information z—for example a data endpoint, noise endpoint, or paired endpoints—and a conditional path pₜ(x | z) whose samples and velocity uₜ(x | z) are available in closed form:

L_CFM(θ) = E_{t,z,xₜ ∼ pₜ(·|z)} [ ||vθ(t, xₜ) - uₜ(xₜ | z)||² ].

Under the usual regularity and consistency conditions, squared-loss regression learns

v*(t, x) = E[uₜ(x | z) | xₜ = x].

This conditional expectation is the marginal velocity associated with pₜ(x) = ∫pₜ(x | z)p(z)dz; averaging the conditional continuity equations recovers the marginal continuity equation. This is a population-optimum result for the specified consistent conditional path, under the required regularity, sufficient model capacity, and successful optimization. Finite data, finite capacity, and optimization error produce only an approximation to that marginal flow.

The computational advantage is central: training draws t and z, constructs xₜ directly, evaluates an analytic conditional velocity, and performs ordinary supervised regression. It does not simulate the current learned ODE to obtain each training example. ODE solving is deferred to sampling (and to likelihood evaluation, if used).

5. Path choices

The endpoints do not determine the journey. The chosen probability path changes regression difficulty, trajectory geometry, and numerical cost.

PathTypical constructionConsequence
Linear Gaussian interpolationxₜ = αₜx_data + σₜε, with ε ∼ N(0,I); conditional target uₜ = α̇ₜx_data + σ̇ₜε.Simple sampling and analytic targets. The schedule controls signal-to-noise ratio and endpoint behavior.
Variance preservingChoose αₜ² + σₜ² = 1, often matching diffusion marginals.Keeps the variance stable for standardized data and gives a direct bridge to diffusion parameterizations.
Optimal-transport-inspiredPair base and data samples to reduce transport cost, then interpolate between paired endpoints.Shorter, less intersecting conditional paths can yield a simpler marginal field, but computing a useful coupling adds cost or approximation.

High curvature forces a solver to take smaller steps. Many conditional paths may also cross at the same (t,x) with different target velocities. Regression averages those directions, which can bend the learned marginal trajectories or make the target ambiguous. This does not mean trajectories of the final well-posed ODE cross: the learned field assigns only one velocity to each (t,x). Better endpoint couplings and path schedules can reduce these conflicting conditional targets.

6. Rectified flow

Rectified flow is a particular flow-matching construction. Draw a base sample x₀ and a data sample x₁, often initially independently, and prescribe the straight conditional interpolation

xₜ = (1 - t)x₀ + tx₁, uₜ(xₜ | x₀,x₁) = x₁ - x₀.

The network regresses the constant endpoint displacement from noisy intermediate points. Although every conditional path is straight, the marginal regression field need not produce straight trajectories: different endpoint lines can cross, and their velocities are averaged.

Reflow improves the coupling. First use a trained flow to map base samples to generated endpoints. Treat each generated endpoint and its originating base sample as a new pair, then retrain on straight interpolations between those coupled endpoints. Repeating this process can reduce crossings and straighten the learned trajectories, at the cost of generating a new paired dataset and retraining.

Straighter, smoother trajectories have lower discretization error under large time steps, so Euler or Heun may reach good quality with fewer network evaluations. This is an empirical advantage, not a guarantee: model approximation error can still dominate.

Do not equate rectified flow with every CNF. A CNF is the broad model class: any learned invertible ODE flow, often trained by likelihood. Rectified flow specifies a straight conditional path, a velocity-regression objective, and optionally reflow. A rectified-flow model is an ODE-based flow and can be viewed as a CNF when used as a density model, but an arbitrary CNF is not rectified flow.

7. Connection to diffusion

A forward diffusion follows an SDE

dx = f(t,x)dt + g(t)dWₜ

that gradually turns data into noise. If sₜ(x) = ∇ₓ log pₜ(x) is the score, the corresponding reverse-time SDE has drift f - g²sₜ plus stochastic noise (with the equation integrated from terminal time back to data time). The same marginal densities are also generated by the deterministic probability-flow ODE

dx/dt = v_PF(t,x), v_PF(t,x) = f(t,x) - ½g(t)²sₜ(x).

This is the score-to-velocity conversion. A learned score can therefore be sampled either stochastically with the reverse SDE or deterministically with the probability-flow ODE. They share one-time marginals in the idealized exact-model setting but not individual trajectories or finite-step errors.

Diffusion and flow matching may use the same Gaussian probability path while predicting different but algebraically convertible targets. Diffusion training commonly estimates a score or noise; flow matching directly estimates a velocity. The objective parameterization, weighting over time, and sampling dynamics—not merely the endpoint distributions—distinguish the methods.

8. Conditioning and guidance

A conditional generator learns vθ(t,x,c), where c may be a class, text sequence, image, audio, spatial map, or any combination. Cross-attention, concatenated features, and modality-specific encoders can inject multimodal context while the ODE state remains the generated sample.

Classifier-free guidance trains with the condition randomly dropped, then combines conditional and unconditional predictions during sampling:

v_guided = v_uncond + w(v_cond - v_uncond).

At w = 1 this equals the conditional prediction; larger w usually strengthens adherence but can reduce diversity, distort the learned field, and increase solver sensitivity. This linear velocity-space combination is an operational guidance construction. It is exactly inherited from score-space classifier-free guidance only when the chosen probability path and parameterization give the stated affine score-to-velocity relation with matching conditional and unconditional coefficients; otherwise its semantics are convention-dependent rather than universally equivalent.

For inpainting, known coordinates can be clamped or projected onto a time-consistent noised version of the observation while the unknown region evolves. Mask-aware training gives the field the information needed to respect the boundary. More general constraints can be imposed through conditioning, projection, or gradient guidance, but modifying the velocity at sampling time changes the transported distribution and can break exact likelihood or invertibility claims.

9. Sampling and numerical solvers

SolverPer-step model evaluationsUse
Euler1Cheapest first-order baseline; effective when the learned path is very straight or the step count is moderate.
Heun2Second-order predictor–corrector that often gives a strong quality/latency trade-off.
Runge–KuttaTypically 4 for classical RK4Higher-order fixed-step accuracy, but extra evaluations may cost more than simply using more lower-order steps.
Adaptive solversVariableAdjust step size from a local truncation-error estimate; useful for difficult paths and likelihoods, less predictable for batched latency.

NFE is the number of neural function evaluations. Because each evaluation is usually a large network forward pass, NFE is a better first latency proxy than step count: ten Heun steps require about twenty evaluations. Wall time also depends on network size, implementation, batching, and hardware.

Solver error and model error are distinct. Tightening tolerances or raising solver order reduces error relative to the learned ODE, but cannot correct an inaccurate velocity field. Diagnose them by comparing several solvers and step sizes: convergence toward the same poor samples suggests model error, while large changes with discretization suggest solver sensitivity. Adaptive methods control numerical error, not perceptual quality.

AxisWhat to measure
Sample qualityDomain-appropriate perceptual metrics, human preference, fidelity, and conditional adherence.
Path curvatureIntegrated acceleration, deviation from endpoint chords, or how much quality improves when steps are added.
Solver sensitivityQuality and output stability across Euler, Heun, higher-order methods, tolerances, and time grids.
LikelihoodBits per dimension or log-likelihood when divergence integration and model assumptions make it available; report trace-estimator and solver settings.
Few-step qualityQuality versus NFE and end-to-end latency, especially at deployment-relevant budgets.

A fair comparison fixes architecture and compute where possible, reports the full quality–NFE curve rather than one favored operating point, and separates training cost, sampling cost, and likelihood cost. Visual smoothness alone can hide mode dropping.

  6. Separate model error, solver error, step count, and NFE.
