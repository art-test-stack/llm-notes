A Gaussian process (GP) is a probability distribution over functions. It combines a prior encoded by a kernel with observed data to produce predictions and input-dependent uncertainty. Exact inference is analytic for Gaussian regression likelihoods; the main costs are dense linear algebra and choosing a kernel whose assumptions match the problem.

Learning objectives

You should be able to define a GP as a function-space prior, design and combine kernels, derive the exact regression posterior, implement it stably with Cholesky solves, explain marginal-likelihood model selection, compare exact and sparse inference, and evaluate both prediction error and uncertainty calibration.

1. Function-space prior

A GP is written

f ~ GP(m, k) m(x) = E[f(x)] k(x, x') = Cov(f(x), f(x'))

The mean function is the prior expected output at each input. A zero mean is common after centering the targets, but a parametric trend can be placed in m(x) when domain knowledge supports it. The kernel, or covariance function, controls which inputs should have correlated function values, how smooth sampled functions are, and how uncertainty changes away from data.

The definition is finite-dimensional: for every set of inputs X = (x_{1}, \ldots , x_{n}),

f_X = [f(x₁), …, f(xₙ)]ᵀ ~ N(m_X, K_XX) (m_X)ᵢ = m(xᵢ), (K_XX)ᵢⱼ = k(xᵢ, xⱼ).

These Gaussian marginals must be mutually consistent as input sets grow or shrink. A valid real-valued kernel is symmetric and positive semidefinite (PSD):

for every X and every a ∈ Rⁿ,     aᵀ K_XX a ≥ 0.

This condition makes every Gram matrix a valid covariance matrix. Strict positive definiteness is not required; repeated inputs, finite-dimensional feature maps, or structured kernels can yield singular covariance matrices. Observation noise or a small numerical jitter often makes the matrix factorable.

Function-space view. A GP does not maintain a finite vector containing the whole random function. It specifies compatible probability distributions for any finite set of evaluations needed by an algorithm.

2. Kernel design

Write r = ‖x − x'‖. The following kernels are common building blocks; amplitudes and length scales are learned or assigned priors.

KernelFormInductive bias
RBF / squared exponential\sigma _f^{2} \operatorname{exp}(-r^{2}/(2\ell ^{2}))Stationary, very smooth functions; correlations decay on scale ℓ.
Matérn\sigma _f^{2} 2^{1-\nu }/Γ(\nu ) (\sqrt{2\nu }r/\ell )^\nu K_\nu (\sqrt{2\nu }r/\ell )Finite, controllable roughness; the process has k mean-square derivatives when \nu \gt k.
Linear\sigma _b^{2} + \sigma _v^{2}(x-c)^{\top}(x'-c)Bayesian linear functions around center c; non-stationary covariance.
Periodic\sigma _f^{2} \operatorname{exp}(-2 \operatorname{sin}^{2}(\pi \mid x-x'\mid /p)/\ell ^{2})Exact repetition with period p and smoothness controlled by ℓ.
Rational quadratic\sigma _f^{2}(1 + r^{2}/(2\alpha \ell ^{2}))^{-\alpha }A scale mixture of RBF kernels; variation can occur across several length scales.

Automatic relevance determination (ARD) replaces one length scale by ℓ_d per input dimension. It can expose irrelevant dimensions, but weak data can make the additional hyperparameters poorly identified.

Sums, products, and inductive bias

PSD kernels are closed under non-negative scaling, sums, and products:

k_sum(x,x') = k₁(x,x') + k₂(x,x') k_prod(x,x') = k₁(x,x') k₂(x,x')

A kernel sum has a constructive representation: if independent latent GPs are explicitly posited, their sum has covariance k_{1}+k_{2}. The latent components are not uniquely identifiable from the summed covariance alone; posterior component attribution follows the chosen prior decomposition. A product requires both similarity notions to hold, creating interactions. For example, linear + periodic models a chosen trend-plus-cycle decomposition, while periodic × RBF models a cycle that changes gradually over time.

3. GP regression

Observation-noise model

For training inputs X = (x_{1},\ldots ,x_{n}), assume independent Gaussian observation noise:

f ~ GP(m, k) yᵢ = f(xᵢ) + εᵢ, εᵢ ~ N(0, σ_n²)

Let r = y - m_{X}, K = K_{XX}, K_{y} = K + \sigma _n^{2}I, K_\cdot = K_{X},X\cdot, and K_\cdot \cdot = K_{X}^{\ast},X\cdot. Here K_* has shape n × n_*.

Joint Gaussian distribution

Closure of Gaussians under affine transformations gives the joint prior over noisy training targets and latent test values:

[ y ] [ m_X ] [ K_y K_* ] [ f_*] ~ N([ m_* ], [ K_*ᵀ K_** ]).

Posterior mean and covariance: derivation

For a partitioned Gaussian [a; b] with mean {}[\mu _a; \mu _b] and covariance blocks \sum _\text{aa}, \sum _\text{ab}, \sum _\text{ba}, and \sum _\text{bb}, complete the square in the joint log density with respect to b. The terms depending on b become

−1/2 (b − μ_b − Σ_ba Σ_aa⁻¹(a−μ_a))ᵀ (Σ_bb − Σ_ba Σ_aa⁻¹Σ_ab)⁻¹ (b − μ_b − Σ_ba Σ_aa⁻¹(a−μ_a)) + constant.

Therefore the conditional is Gaussian. Substituting a=y, b=f_\cdot, \sum _\text{aa}=K_{y}, and \sum _\text{ba}=K_\cdot ^{\top} yields

f_* | X, y, X_* ~ N(μ_*, Σ_*) μ_* = m_* + K_*ᵀ K_y⁻¹(y − m_X) Σ_* = K_** − K_*ᵀ K_y⁻¹K_*.

The posterior mean is the prior mean plus a data-dependent linear combination of kernel evaluations. The covariance is the prior covariance minus uncertainty resolved by observing y; for fixed hyperparameters it depends on input locations, not observed target values.

Predictive distribution

For a future noisy observation y_\cdot = f_\cdot + \varepsilon _\cdot, independent noise adds back onto the diagonal:

y_* | X, y, X_* ~ N(μ_*, Σ_* + σ_n²I).

Distinguish the latent-function posterior from the observation predictive distribution. The latter is wider because it includes irreducible measurement noise.

Worked two-point numerical example

Take x=[0,1], y=[1,-1], zero mean, unit signal variance, noise variance \sigma _n^{2}=0.1, and an RBF length scale chosen so k(0,1)=0.5. At x_\cdot =0.5, both cross-covariances are a=2^{-1/4}\approx 0.8409:

K_y = [1.1 0.5] K_y⁻¹ = 1/0.96 [ 1.1 −0.5] [0.5 1.1] [−0.5 1.1] k_* = [a, a]ᵀ, k_** = 1.

The solve gives K_{y}^{-1}y=[1.6667,-1.6667]^{\top}. Symmetry makes the midpoint posterior mean zero:

μ_* = [a, a] [1.6667, −1.6667]ᵀ = 0. Var(f_* | y) = 1 − [a,a] K_y⁻¹ [a,a]ᵀ = 1 − a²(1.25) ≈ 0.1161. Var(y_* | y) = 0.1161 + 0.1 = 0.2161.

Thus the latent prediction is approximately N(0, 0.1161), with a 95% Gaussian interval 0 ± 0.668. A new noisy measurement has the wider predictive distribution N(0, 0.2161), with interval 0 ± 0.911. The zero mean is not “no information”: it reflects opposing observations, while the reduced variance records information about the midpoint.

4. Marginal likelihood

Integrating out the latent training values gives y ~ N(m_X, K_y). The log marginal likelihood for kernel and noise hyperparameters \theta is

log p(y | X, θ) = −1/2 rᵀK_y⁻¹r data fit −1/2 log|K_y| complexity / volume penalty −n/2 log(2π). normalization

The data-fit term rewards covariance structures under which the residual vector is plausible. The log-determinant term penalizes models that spread probability mass over too large a range of possible datasets. Their balance is an automatic Occam effect: a flexible kernel is favored only when its improved fit compensates for its larger covariance volume.

Model selection can compare kernel families or tune amplitudes, length scales, periodicities, noise, and mean-function parameters by maximizing this objective (type-II maximum likelihood / empirical Bayes). Gradients follow

∂ log p(y|θ)/∂θ_j = 1/2 tr[(ααᵀ − K_y⁻¹) ∂K_y/∂θ_j], α = K_y⁻¹r.

Use positive transforms or log parameters for constrained quantities, multiple restarts for a non-convex objective, and held-out evaluation when comparing many choices. Marginal likelihood is evidence conditional on the candidate model family; it cannot rescue a misspecified kernel, and point-estimating hyperparameters understates uncertainty relative to integrating them out.

Numerical conditioning

Very small noise, duplicated or nearly duplicated inputs, extreme length scales, and mixed feature units can make K_{y} ill-conditioned. Symptoms include failed factorization, unstable gradients, tiny negative variances from roundoff, and implausible likelihood values. Standardize inputs and targets, constrain hyperparameters sensibly, use adequate precision, and add the smallest justified jitter.

5. Numerical implementation

Never form K_y⁻¹ explicitly. Compute a Cholesky factorization K_{y} + \delta I = LL^{\top}, with lower-triangular L, then use triangular solves:

L v = y − m_X forward solve Lᵀ α = v backward solve μ_* = m_* + K_*ᵀ α L V = K_* one solve per test column Σ_* = K_** − VᵀV log|K_y| = 2 Σᵢ log Lᵢᵢ.

Jitter is a small diagonal value \delta used for numerical stability, distinct from modeled observation noise \sigma _n^{2}. Scale it relative to the kernel diagonal and report it if it is large enough to affect inference.

Dense factorization costs O(n^{3}) time and the kernel/factor requires O(n^{2}) storage. After factorization, posterior-mean evaluation uses solves and matrix-vector products; full test covariance can itself be expensive. Cache the factor and \alpha, batch test inputs, and request marginal variances instead of a full covariance when that is all the application needs.

6. Sparse Gaussian processes

Exact GPs condition on all n observations. Sparse methods summarize the function using m ≪ n inducing variables u=f(Z) at learned or selected inducing inputs Z. The approximation routes dependence between training and test values through u.

In a variational sparse GP, choose q(u)=N(m_u,S_u) and retain the exact conditional p(f|u). Optimize the evidence lower bound (ELBO):

log p(y) ≥ Σᵢ E_q(fᵢ)[log p(yᵢ|fᵢ)] − KL[q(u) || p(u)].

The sum over observations supports mini-batches and stochastic optimization. Typical dense-inducing costs are O(\text{nm}^{2} + m^{3}) for a full pass, with storage around O(\text{nm} + m^{2}); mini-batching removes the need to process or store all n cross-covariances at once.

Too few inducing points can oversmooth the mean and underestimate or distort uncertainty. More points improve fidelity but increase cost. Compare against exact inference on a manageable subset, inspect sensitivity to m, and evaluate calibration rather than selecting an approximation only by RMSE.

7. Classification

For binary classification, place a GP prior on latent logits and use a sigmoid or probit likelihood:

f ~ GP(m,k), p(yᵢ=1 | fᵢ) = sigmoid(fᵢ).

The Bernoulli likelihood is non-Gaussian, so the posterior p(f|y) and evidence are not analytic.

  • Laplace approximation: find the posterior mode and use a Gaussian whose covariance is the inverse negative Hessian there. It is often practical but captures only local curvature and can be poor for skewed posteriors.
  • Variational approximation: optimize a tractable q(f) or inducing-variable q(u) against an ELBO. It scales to mini-batches but its family and objective can bias uncertainty.

A predictive class probability integrates over latent uncertainty:

p(y_*=1 | data) = ∫ sigmoid(f_*) p(f_* | data) df_*.

This is not generally \operatorname{sigmoid}(E[f_\cdot ]). Use analytic probit identities when applicable, numerical quadrature, or Monte Carlo. Assess predictive probabilities with NLL, Brier score, reliability diagrams, and calibration under shift; approximate inference can be accurate in labels yet overconfident.

8. Multi-output and structured GPs

Coregionalization

Multi-output GPs couple tasks or sensors. A linear model of coregionalization uses

k((x,p),(x',q)) = Σᵣ Bᵣ[p,q] kᵣ(x,x'),

where each PSD matrix Bᵣ describes output correlations and each kᵣ describes an input-space pattern. Shared structure can transfer information, but a wrong coupling can cause negative transfer.

Spatiotemporal, derivative, and physics-informed structure

  • Spatiotemporal kernels: an additive or product kernel over space and time expresses separate or interacting correlations. Separable products can enable Kronecker or state-space computations on suitable grids.
  • Derivative observations: differentiation is linear, so derivatives of a sufficiently smooth GP remain jointly Gaussian. For example, Cov(∂f(x)/∂x_d, f(x')) = ∂k(x,x')/∂x_d, and derivative-derivative covariance uses derivatives with respect to both arguments.
  • Physics-informed kernels: transform latent GPs through known linear operators, use Green's functions, or design kernels whose samples satisfy boundary conditions, symmetries, conservation laws, or differential equations.

Kernel differentiability must match the desired operators: an RBF supports derivatives of every order, while a rough Matérn kernel may not. Hard physics constraints can improve data efficiency but become harmful when the assumed equation or boundary conditions are wrong; soft residual likelihoods allow model discrepancy.

9. Connection to neural networks

  • Infinite-width limits: under suitable independent weight priors and scaling, a neural network's outputs converge in distribution to a GP as hidden widths go to infinity. The architecture, activation, and initialization induce the corresponding neural-network GP kernel.
  • Neural tangent kernel (NTK): in an infinite-width regime, gradient descent can be described by kernel dynamics around initialization. The NNGP describes a prior over functions; the NTK describes linearized training dynamics. Neither automatically captures finite-network representation learning.
  • Deep-kernel learning: a neural feature map h_\phi (x) feeds a GP kernel, k_\theta (h_\phi (x),h_\phi (x')). It combines learned representations with GP predictions, but joint marginal-likelihood training can overfit features and produce misleading uncertainty without regularization and held-out calibration checks.

10. Evaluation

A GP should be judged as a predictive distribution, not only as a point predictor.

MeasureWhat it testsMain caveat
Negative log-likelihood (NLL)Joint quality of predictive location and scale; heavily penalizes confident errorsCan be dominated by a few outliers and depends on the likelihood model
RMSEAccuracy of the predictive meanIgnores uncertainty entirely
Interval coverageWhether nominal q% intervals contain about q% of outcomesCoverage without sharpness can reward uselessly wide intervals
CalibrationAgreement between predictive probabilities/quantiles and empirical frequenciesAggregate calibration can hide errors by region or subgroup

For regression, inspect coverage at several levels, interval width, standardized residuals, and probability-integral-transform values. Report metrics both globally and by input region. Hyperparameter uncertainty, approximate inference, and selection on the test set can all make intervals too narrow.

Extrapolation and kernel misspecification

Far from observations, a stationary GP usually reverts toward its prior mean and variance. That is coherent under the model but may be poor extrapolation: an RBF does not infer an ongoing linear trend unless the mean or kernel represents one, and a periodic kernel may continue a cycle forever. Test interpolation and extrapolation separately using splits that reflect deployment geometry, such as future-time or held-out-region splits rather than random splits.

Kernel misspecification can produce smooth, confident, wrong predictions. Stress-test plausible kernel families, inspect residual structure, evaluate under covariate shift, and compare posterior intervals with empirical errors. Good in-distribution marginal likelihood does not guarantee calibrated out-of-distribution uncertainty.
