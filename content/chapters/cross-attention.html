Learning objectives

You should be able to trace a complete encoder-decoder forward pass, derive cross-attention shapes for MHA and GQA, distinguish teacher-forced training from cached autoregressive decoding, account for compute and cache memory, and implement and test the masks without mixing source validity with target causality.

Transformer families

  • Encoder-only: bidirectional self-attention creates contextual representations; suited to classification, retrieval, and token labeling.
  • Decoder-only: causal self-attention predicts the next token; suited to generative language modeling.
  • Encoder-decoder: an encoder represents the source, while a causal decoder generates the target using self-attention and cross-attention.

The architectural distinction is the allowed information flow, not merely model size.

Notation and tensor layout

Let B be batch size, S = T_{\text{source}} the padded source length, T = T_{\text{target}} the padded target length, D model width, F feed-forward width, H_{q} query heads, H_{\text{kv}} key/value heads, and D_{h} = D/H_{q}. Examples use the head-major layout [B, heads, time, D_h].

Full encoder-decoder computation

The encoder consumes every valid source token at once. Each encoder layer applies bidirectional self-attention over valid source positions, then a position-wise feed-forward network (FFN). “Bidirectional” means there is no triangular mask; source padding is still masked.

E⁰ = source_embedding(source_ids) + source_position
for encoder layer ℓ:
    E′ = E + SelfAttention(LN(E), source_key_mask)   # all valid source pairs
    E  = E′ + FFN(LN(E′))

The decoder receives a right-shifted target. Every decoder layer first applies causal self-attention, then cross-attention whose queries come from the decoder and whose keys and values come from the final encoder states, then an FFN.

decoder_input = [BOS, y₀, y₁, …, y_(T-2)]
labels        = [y₀,  y₁, y₂, …, y_(T-1)]

D⁰ = target_embedding(decoder_input) + target_position
for decoder layer ℓ:
    D′  = D + CausalSelfAttention(LN(D), causal_and_target_padding_mask)
    D″  = D′ + CrossAttention(LN(D′), encoder_states, source_padding_mask)
    D   = D″ + FFN(LN(D″))
logits = LN(D) W_vocab
loss   = cross_entropy(logits, labels, ignore_index=PAD)

This is a pre-norm stack: normalization is inside each residual branch, which usually improves optimization in deep networks. In a post-norm stack each sublayer instead computes x = LN(x + \operatorname{Sublayer}(x)). Do not silently mix the two: checkpoint parameters, final normalization, and gradient behavior differ. FFNs are independently applied to each time position, commonly as W_{2} \text{activation}(W_{1}x) or a gated variant such as SwiGLU.

During teacher-forced training, the complete shifted target is known, so all target positions run in parallel. The causal mask prevents position t from seeing later target tokens even though they are present in the same tensor. Cross-attention may use the complete encoded source at every target position.

Cross-attention equations and shapes

For decoder states X_d ∈ R[B,T,D] and encoder states X_e ∈ R[B,S,D], a decoder cross-attention sublayer computes:

Q = split_heads(X_d W_Q) ∈ R[B, H_q, T, D_h] K = split_heads(X_e W_K) ∈ R[B, H_kv, S, D_h] V = split_heads(X_e W_V) ∈ R[B, H_kv, S, D_h] A_i = softmax((Q_i K_g(i)ᵀ) / √D_h + M_source) ∈ R[B, T, S] O_i = A_i V_g(i) ∈ R[B, T, D_h] Y = concat(O_0, …, O_(H_q-1)) W_O ∈ R[B, T, D]

In standard multi-head attention (MHA), H_{\text{kv}} = H_{q} and g(i)=i. In grouped-query attention (GQA), H_{q} must be divisible by H_{\text{kv}} and several query heads share one KV head; a common mapping is g(i)=\text{floor}(i H_{\text{kv}}/H_{q}). Multi-query attention (MQA) is the special case H_{\text{kv}}=1. GQA/MQA reduce projection and cache memory for K/V; they do not change the logical score shape [B,H_q,T,S].

If source_keep is Boolean with shape [B,S], broadcast it as [B,1,1,S] across query heads and target positions. An additive mask contains 0 for valid source keys and -\infty for padding. A Boolean mask API may define either keep or block semantics, so check the specific primitive before passing it.

source_keep: [B, S]
cross_keep:  [B, 1, 1, S]       # broadcast to [B, H_q, T, S]
causal_keep: [1, 1, T, T]       # lower triangular; decoder self-attention only

Source and target lengths need not match. A target-index triangle over the source axis is almost always wrong: target position zero is allowed to attend to the final valid source token. If padded query rows must remain exactly zero, mask or zero them after each residual block as well as masking padded keys.

Training versus autoregressive inference

ConcernTeacher-forced trainingAutoregressive inference
Target inputEntire right-shifted targetOne newly selected token at a time after optional prompt prefill
ParallelismAll T target positionsSequential across generated positions; batched across requests or beams
Decoder self-attentionTriangular causal mask over [T,T]New query attends to all cached prefix K/V; no future cache entry exists
Cross-attentionAll target queries attend to the fixed encoded sourceOne new query attends to the same fixed encoded source
Stored K/VUsually temporary activations for backpropagationGrowing decoder self K/V plus fixed encoder-side cross K/V per decoder layer

Two different caches

  1. Decoder self-attention cache: each decoder layer appends the new token's K/V. At step t, its shape is approximately [B,H_kv,t,D_h] for K and again for V. It grows with generated length and differs between sequences and beams.
  2. Encoder-side cross-attention cache: after encoding, each decoder layer applies its own cross-attention W_{K} and W_{V} once and stores [B,H_kv,S,D_h]. These projections are immutable throughout decoding. “Cache the encoder output” alone is not equivalent: repeatedly projecting that output still wastes work.

With beam width W, encode each source and compute its per-layer cross K/V once. Keep a beam_to_source mapping so all beams can reference the same immutable source storage instead of copying it W times. After top-k parent selection, reorder the decoder self-attention cache, token histories, lengths, and scores by the parent indices. The shared source cache normally needs only its logical mapping reordered. Paged or reference-counted storage can make both source sharing and common-prefix sharing copy-on-write operations. See inference, decoding, and KV caches for the serving details.

Complexity and memory

Let L_{e} be encoder layers and L_{d} decoder layers; let L_{x} \le L_{d} contain cross-attention. Ignoring constants and projection/FFN terms, dense attention costs are:

ComponentTraining computeAttention-score memory
Encoder bidirectional self-attentionO(B L_{e} S^{2} D)O(B L_{e} H_{q} S^{2}) without memory-efficient kernels/checkpointing
Decoder causal self-attentionO(B L_{d} T^{2} D)O(B L_{d} H_{q} T^{2})
Decoder cross-attentionO(B L_{x} T S D)O(B L_{x} H_{q} T S)

Linear projections add roughly O(BS D^{2}) or O(BT D^{2}) per layer, and FFNs add O(B(S+T)DF). At one-token decoding, self-attention reads a growing prefix and cross-attention reads the fixed source, so the attention work per decoder layer is O(\text{tD} + SD). Summed over generated tokens, cross-attention remains O(TSD).

The mutable decoder cache uses 2 B L_d H_kv t D_h elements. Fixed source projection caches use 2 B L_x H_kv S D_h elements and can dominate when the source is long or cross-attention appears in every layer. GQA/MQA, lower-precision K/V, and beam-wise source sharing reduce cache bytes, but only source compression or sparse selection reduces the number of source positions read.

Long-source mitigations include chunking or hierarchical encoders, retrieval of only relevant passages, local/sparse encoder attention, selecting or pooling source tokens, latent bottlenecks, and cross-attention in fewer layers. Flash-style kernels reduce materialized score memory but not the T×S arithmetic. Each mitigation trades exact global access for selection or compression; measure evidence recall, not only accepted length. See long-context modelling.

Alignment, copying, and source use

  • Attention alignment: cross-attention weights often correlate with source-target alignment, especially in translation, but they are head- and layer-dependent internal routing values, not guaranteed explanations or calibrated probabilities of causation.
  • Pointer/copy mechanisms: a pointer-generator mixes a vocabulary distribution with a distribution formed by summing cross-attention mass over source positions containing the same token. A learned gate chooses generation versus copying, which helps rare names and exact spans.
  • Coverage: accumulating prior attention, coverage_s(t)=Σ_(τ<t) A_(τ,s), exposes already-used source positions. A coverage feature or overlap penalty can discourage repetition and omission, though monotonic coverage assumptions do not fit every task.
  • Conditioning collapse: a strong decoder may minimize training loss using target-side regularities while ignoring the source. Diagnose by shuffling, masking, or counterfactually changing sources and measuring the change in likelihood/output, not just by plotting attention.

Mitigations for source neglect include stronger or better-aligned conditioning data, auxiliary alignment/contrastive losses, source dropout schedules chosen carefully, gated-module initialization that actually opens during training, and architectural placement that gives the conditioning path enough depth. Always compare against a decoder-only or shuffled-source baseline.

PyTorch-like implementation pseudocode

The following uses one explicit convention: Boolean keep=True means an attention pair is allowed. A production fused attention API may use the opposite convention.

def masks(source_ids, decoder_ids, pad_id):
    # source_keep: [B,S]; target_keep: [B,T]
    source_keep = source_ids.ne(pad_id)
    target_keep = decoder_ids.ne(pad_id)
    T = decoder_ids.size(1)

    cross_keep = source_keep[:, None, None, :]          # [B,1,1,S]
    causal = torch.ones(T, T, dtype=torch.bool).tril()  # [T,T]
    self_keep = (causal[None, None, :, :]
                 & target_keep[:, None, None, :])      # [B,1,T,T]
    return source_keep, target_keep, self_keep, cross_keep

def attend(q, k, v, keep):
    # q:[B,Hq,Tq,Dh], k/v:[B,Hkv,Tk,Dh], keep broadcastable to [B,Hq,Tq,Tk]
    Hq, Hkv = q.size(1), k.size(1)
    assert Hq % Hkv == 0
    if Hq != Hkv:                                      # conceptual GQA expansion
        k = k.repeat_interleave(Hq // Hkv, dim=1)      # fused kernels avoid the copy
        v = v.repeat_interleave(Hq // Hkv, dim=1)
    score = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))
    score = score.masked_fill(~keep, float("-inf"))
    prob = score.softmax(dim=-1)
    return prob @ v

def encode(source_ids, source_keep, encoder_layers):
    x = source_embed(source_ids)
    for layer in encoder_layers:                       # pre-norm encoder
        keep = source_keep[:, None, None, :]           # [B,1,1,S], no triangle
        x = x + layer.self_attn(layer.self_norm(x), keep=keep)
        x = x + layer.ffn(layer.ffn_norm(x))
        x = x * source_keep[..., None]                 # zero padded query rows
    return encoder_final_norm(x)

def train_forward(source_ids, target_ids, pad_id):
    decoder_ids = shift_right(target_ids, BOS)          # [B,T]
    src_keep, tgt_keep, self_keep, cross_keep = masks(
        source_ids, decoder_ids, pad_id)
    enc = encode(source_ids, src_keep, encoder_layers)  # [B,S,D]

    # Projections are layer-specific. In training they live for this forward;
    # at inference prepare_source() stores them for every decode step.
    source_kv = [layer.cross_attn.project_kv(enc) for layer in decoder_layers]
    x = target_embed(decoder_ids)
    for layer, (source_k, source_v) in zip(decoder_layers, source_kv):
        x = x + layer.self_attn(layer.self_norm(x), keep=self_keep)
        q = layer.cross_attn.project_q(layer.cross_norm(x))
        x = x + layer.cross_attn.from_qkv(q, source_k, source_v,
                                           keep=cross_keep)
        x = x + layer.ffn(layer.ffn_norm(x))
        x = x * tgt_keep[..., None]
    logits = lm_head(decoder_final_norm(x))
    return cross_entropy(logits.flatten(0, 1), target_ids.flatten(),
                         ignore_index=pad_id)

Cached source projections and one-token decode

def prepare_source(source_ids, pad_id):
    source_keep = source_ids.ne(pad_id)                 # [B,S]
    enc = encode(source_ids, source_keep, encoder_layers)
    cross_kv = [layer.cross_attn.project_kv(enc)        # each K/V: [B,Hkv,S,Dh]
                for layer in decoder_layers]
    return {"keep": source_keep[:, None, None, :], "kv": cross_kv}

def decode_step(token, position, source, self_cache):
    # token:[Bbeam,1]; source may be a zero-copy view through beam_to_source.
    x = target_embed(token, position)
    next_cache = []
    for i, layer in enumerate(decoder_layers):
        u = layer.self_norm(x)
        q, k_new, v_new = layer.self_attn.project_qkv(u)
        k = torch.cat([self_cache[i].k, k_new], dim=2)
        v = torch.cat([self_cache[i].v, v_new], dim=2)
        # The only query is newest; every existing cache position is in its past.
        x = x + layer.self_attn.from_qkv(q, k, v, keep=True)

        source_k, source_v = source["kv"][i]
        q_cross = layer.cross_attn.project_q(layer.cross_norm(x))
        x = x + layer.cross_attn.from_qkv(
            q_cross, source_k, source_v, keep=source["keep"])
        x = x + layer.ffn(layer.ffn_norm(x))
        next_cache.append(Cache(k, v))
    return lm_head(decoder_final_norm(x[:, -1])), next_cache

# Beam update after selecting parent_beam:[B*W]. Source K/V remains shared.
self_cache = [c.index_select_batch(parent_beam) for c in self_cache]
beam_to_source = beam_to_source.index_select(0, parent_beam)

Real implementations preallocate or page the growing self cache instead of concatenating every step. They should also reject all-masked source rows or provide a defined null source, because softmax over only -\infty values yields undefined/NaN probabilities.

Mask and cache correctness tests

def test_mask_shapes_and_meanings():
    src = tensor([[7, 8, PAD]])
    dec = tensor([[BOS, 4, 5, PAD]])
    _, _, self_keep, cross_keep = masks(src, dec, PAD)
    assert self_keep.shape == (1, 1, 4, 4)
    assert cross_keep.shape == (1, 1, 1, 3)
    assert not self_keep[0, 0, 0, 1]       # target 0 cannot see future target 1
    assert self_keep[0, 0, 2, 0]           # target 2 can see earlier target 0
    assert cross_keep[0, 0, 0, 1]          # target 0 may see later-indexed source 1
    assert not cross_keep[0, 0, 0, 2]      # source padding is hidden for every query

def test_future_target_cannot_change_past_logits(model):
    # eval() disables dropout; changing decoder input 2 cannot change logits 0..1.
    model.eval()
    d1 = tensor([[BOS, 10, 11]])
    d2 = tensor([[BOS, 10, 99]])
    assert_close(model.decode_inputs(src, d1)[:, :2],
                 model.decode_inputs(src, d2)[:, :2])

def test_source_padding_cannot_change_decoder_output(model):
    # Perturb encoder states only at a padded source position.
    enc1 = model.encode(src)
    enc2 = enc1.clone(); enc2[:, -1] = 1e6
    assert_close(model.decode_from_encoder(dec, enc1, src_keep),
                 model.decode_from_encoder(dec, enc2, src_keep))

def test_cached_decode_matches_full_prefix(model):
    source = model.prepare_source(src)
    cached_logits = model.decode_token_by_token(prefix, source)
    full_logits = model.decode_full_causal(prefix, source)
    assert_close(cached_logits, full_logits, atol=1e-5, rtol=1e-5)

Also test batches with unequal source/target lengths, H_{q} \gt H_{\text{kv}}, a single valid source token, beam parent indices containing duplicates, and both Boolean and additive mask adapters. The key invariant is that changing future targets cannot affect past logits, while changing any valid source position is permitted to affect every target position.

Failure modes

  • Q taken from the source instead of decoder state;
  • applying the decoder causal mask to source positions;
  • mask convention reversed;
  • source padding broadcast over the wrong dimensions;
  • decoder ignoring the conditioning signal;
  • recomputing source projections at every decode step;
  • incompatible query/KV head counts.
  • copying immutable source K/V once per beam or failing to reorder mutable decoder caches;
  • training on an unshifted target, which leaks the token being predicted;
  • creating NaNs for examples whose source mask contains no valid key.
